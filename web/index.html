Start the local server

Knightlab needs its local server to run. Opening this HTML file directly cannot start the app.

  1. Extract the project folder and install Python 3.11 or newer if needed.
  2. In the project folder, double-click start.bat on Windows or Start.command on macOS. On Linux, run ./start.sh.
  3. Keep the Terminal window open, then visit http://127.0.0.1:8765.

About Knightlab

Knightlab runs on your computer. Sessions and imported puzzles stay in your local database.

Board controls

Drag a piece to a highlighted destination, or click the piece and destination. Turn off Drag pieces above the board for click-only play. Your move and the opponent’s reply animate in sequence. You can also use the arrow keys to move around the board and Enter or Space to select a square. Play the complete puzzle line. Timed sprints advance automatically after each solution; Free Practice and Intuition use Next.

How intuition is scored

Stockfish evaluates real-game positions and your move from the same player's perspective. Centipawn loss is the difference between the best move and your move. The training score is 100 × exp(−loss / 200). It is not an Elo rating or Lichess accuracy.

Import formats

Puzzles: Lichess CSV / CSV.zst, or the JSON schema documented in the project README. Intuition: a PGN of real games, analyzed by your local Stockfish engine.
